세션 1 · 35분 · AI와 기획서 쓰기

AI에게 쉬운 말로 앱 계획부터 부탁하세요

나는 코딩을 전혀 모르는 영어 선생님이야. 영어 학습 앱을 하나 만들고 싶어. 내가 만들고 싶은 건 이거야: "[내가 만들고 싶은 앱을 한 문장으로 요약해서 작성]" 이걸 어떻게 만들면 좋을지, 나 대신 한 장짜리 '계획표'로 정리해줘. 이런 게 들어가면 좋겠어: · 누구를 위한 앱인지 (학년·수준) · 가장 중요한 기능 딱 한 가지 · 화면에 무엇이 보이면 되는지 · 단어는 몇 개, 어떤 정보(뜻·예문 등)가 필요한지 · 학생이 무엇을 할 수 있으면 성공인지 어려운 말은 쉽게 풀어서 설명해주고, 더 알아야 할 게 있으면 나한테 하나씩 물어봐 줘.

👉 선생님의 판단: 이 기능이 실제 교실에서 쓸모 있나? 너무 복잡하면 "기능 한 가지로 더 줄여줘"라고 말하면 됩니다.

세션 1 · 생성형 AI 지침

📋 기획서 작성 프롬프트 예

나는 코딩을 전혀 모르는 초보 영어교사야. 바이브코딩으로 처음 앱을 만들어 보려고 해. 내가 만들고 싶은 앱은: "영어 단어를 보고 한국어 뜻을 맞추는 간단한 단어 퀴즈 앱" 이야. 너는 교육용 앱 기획자라고 생각하고 아래 형식으로 아주 쉽게 기획서를 작성해줘. [형식] 1) 누구를 위한 앱인지 (학년·수준) 2) 가장 중요한 기능 한 가지 3) 화면에 무엇이 보이나 4) 학습 데이터 (단어 몇 개, 어떤 정보) 5) 무엇을 하면 성공인가

👉 따옴표 안 한 문장만 내 앱으로 바꾸면 끝 — 그대로 복사해 생성형 AI에 붙여넣으세요.

세션 2 · 검증

영어 선생님의 진짜 역할 🎯

바이브코딩에서 선생님의 일은 '코드 짜기'가 아니라 — AI가 만든 학습 데이터가 교육적으로 옳은지 검증하는 것입니다. (오른쪽이 검증 대상)

  • 뜻·예문이 정확한가? (AI는 가끔 틀린 뜻·어색한 예문을 만듭니다)
  • 난이도가 우리 학생에게 맞나? 오답 보기가 너무 뻔하거나 헷갈리지 않나?
  • 문화·맥락이 교실에 자연스러운가?
  • 틀린 건 그 자리에서 고치기 — 학습자를 아는 선생님만 할 수 있는 판단.

AI는 빠르게 초안을, 옳고 그름의 책임은 선생님에게. → 그래서 데이터를 직접 보고 검증하는 것이 진짜 역할.

세션 3 · 한 파일 = 4가지 요소

index.html 안엔 HTML·CSS·JS·데이터가 함께

  • HTML — 화면 구조 (제목·입력칸·버튼·결과)
  • CSS — 글꼴·여백·색 등 디자인
  • JavaScript — 버튼 클릭 시 계산·동작
  • 데이터 — 단어 목록·설정값 등

→ 이 4가지가 한 파일에 다 들어 있어 더블클릭만으로 동작합니다.
