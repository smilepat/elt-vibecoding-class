index.html 한 파일 안의 4가지 요소

파랑 = HTML 화면 구조 초록 = CSS 디자인 노랑 = JavaScript 동작 보라 = 데이터 회색 = 설명 주석
<!DOCTYPE html> <html> <head> <title>수익 계산기</title> <style> /* CSS 영역: 화면을 예쁘게 꾸미는 부분 */ body { font-family: Arial; padding: 30px; } button { background: blue; color: white; padding: 10px 20px; } </style> </head> <body> <!-- HTML 영역: 사용자가 보는 화면 구조 --> <h1>수익 계산기</h1> <p>월 매출을 입력하세요</p> <input id="sales" placeholder="예: 5000000"> <p>월 비용을 입력하세요</p> <input id="cost" placeholder="예: 3000000"> <!-- 버튼을 누르면 JavaScript 함수 calculate()가 실행됨 --> <button onclick="calculate()">계산</button> <!-- 계산 결과가 여기에 표시됨 --> <p id="result"></p> <script> // JavaScript 영역: 버튼 클릭 후 실제 계산을 담당 // 데이터 영역: 앱 안에 미리 넣어둔 기본 정보 let appName = "수익 계산기"; function calculate() { // 1. HTML 화면에서 사용자가 입력한 매출 값을 가져옴 let sales = Number(document.getElementById("sales").value); // 2. HTML 화면에서 사용자가 입력한 비용 값을 가져옴 let cost = Number(document.getElementById("cost").value); // 3. 이익을 계산함 let profit = sales - cost; // 4. 계산 결과를 다시 HTML 화면에 표시함 document.getElementById("result").innerText = "이익: " + profit + "원"; } </script> </body> </html>

HTML

화면에 보이는 제목, 입력칸, 버튼, 결과 표시 공간을 만듭니다.

CSS

글꼴, 여백, 버튼 색깔처럼 화면의 모양을 정합니다.

JavaScript

사용자가 버튼을 눌렀을 때 값을 가져오고 계산하고 결과를 보여줍니다.

데이터

앱 안에 저장된 단어 목록, 설정값, 샘플 정보 등이 들어갈 수 있습니다.
