# 🧑‍🏫 elt-vibecoding-class

> **영어교사를 위한 바이브 코딩 강의·워크숍 자료**
> 코딩 지식 없는 영어교사가 AI에게 말로 시켜(vibe coding) **어휘 학습앱**을 직접 만드는 과정을 다룹니다.

---

## 📚 자료 구성

| 자료 | 대상 | 핵심 컨셉 | 시간 |
|------|------|-----------|------|
| [영어교사_바이브코딩_워크숍.md](영어교사_바이브코딩_워크숍.md) | 코딩 경험 0 교사 | **내 단어장**으로 플래시카드 앱 만들기 | 4시간 |
| [지문기반_어휘학습앱_강의안.md](지문기반_어휘학습앱_강의안.md) | 지문 수업 교사 | **수업 지문**을 어휘 학습앱으로 전환 (맥락 기반) | 3시간 |

### 두 자료의 차이
- **워크숍** = 단어 리스트 기반 (decontextualized) → 플래시카드·퀴즈·간격반복
- **강의안** = 지문 기반 (in context) → 빈칸채우기·문맥추론·동의어·콜로케이션

두 자료 모두 다음 철학을 공유합니다:
> "교사는 **코드를 짜는 사람**이 아니라 **요구를 명확히 설명하는 사람**이다.
> 좋은 앱은 좋은 코드가 아니라 **좋은 데이터 + 명확한 학습 설계**에서 나온다 — 그 둘은 교사가 이미 전문가다."

---

## 🎯 학습 결과물

워크숍/강의가 끝나면 모든 참가 교사가:
1. 동작하는 어휘 학습앱 1개 (HTML 한 파일)
2. 학생에게 보낼 수 있는 **배포 링크**
3. 다음 단어장/지문에 재사용하는 **템플릿**

을 가져갑니다.

---

## 🛠️ 사용 도구 (모두 무료 플랜으로 가능)

- **AI 코딩**: Claude / ChatGPT (입문), v0.dev / Bolt.new / Lovable (디자인)
- **배포**: Netlify Drop / Vercel
- **데이터**: 구글시트 → CSV

---

## 🔗 관련 데이터 생태계

이 자료는 [smilepat/vocabulary-db](https://github.com/smilepat/vocabulary-db) 의
어휘·지문 데이터 구조(9,000단어, 원문→빈칸→Word Bank→타겟어휘)를 기반으로 설계되었습니다.
실제 데이터·AI 자동 추출·IRT 적응 출제로 확장 시 해당 레포의 `APP_DEVELOPMENT_GUIDE.md` 참조.
