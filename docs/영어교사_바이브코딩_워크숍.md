# 영어교사를 위한 바이브 코딩 워크숍

## "코딩 모르는 내가, 내 어휘 학습앱 만들기"

> **한 줄 목표**: 워크숍이 끝나면, 참가 교사 모두가 **자기 단어장으로 동작하는 어휘앱을 학생에게 링크로 보낼 수 있다.**

---

## 0. 워크숍 개요

| 항목 | 내용 |
|------|------|
| **대상** | 코딩 경험 0인 영어교사 (엑셀/구글시트만 다룰 줄 알면 됨) |
| **인원** | 8~16명 (2인 1조 권장 — 1명이 막히면 짝이 도움) |
| **시간** | 4시간 (반일) 또는 2시간×2회 |
| **준비물** | 노트북, 인터넷, 구글 계정, AI 도구 계정(아래) |
| **결과물** | ① 동작하는 플래시카드 앱 1개 ② 학생 공유용 링크 ③ 재사용 프롬프트 모음 |

### 핵심 철학 — 교사에게 미리 안내할 것
> "여러분은 **코드를 짜는 사람**이 아니라 **AI에게 요구를 명확히 설명하는 사람**입니다.
> 좋은 앱은 좋은 코드가 아니라 **좋은 단어장 + 명확한 학습 설계**에서 나옵니다.
> 그 둘은 여러분이 이미 전문가입니다."

## 사전 준비 (워크숍 1주일 전 — 운영자 체크리스트)

### 운영자가 미리 할 일
- [ ] AI 도구 계정 발급 안내 메일 발송 (아래 택1, **무료 플랜으로 충분**)
  - 가장 쉬움: **Claude** (claude.ai) 또는 **ChatGPT**
  - 화면까지 예쁘게: **v0.dev**, **Bolt.new**, **Lovable**
- [ ] 배포용 **Vercel** 또는 **Netlify** 계정 (구글 로그인 1초)
- [ ] 공용 "샘플 단어장 CSV" 1개 준비 (단어장 없는 교사용 — 50단어면 충분)
- [ ] 실습용 **프롬프트 카드**(이 문서 부록) 인쇄 또는 공유

### 참가 교사가 미리 할 일 (사전과제)
- [ ] **내 단어장을 구글시트로 정리** — 이게 진짜 사전과제다
  - 최소 컬럼: `단어 / 뜻 / 예문` (3개면 시작 가능)
  - 권장 컬럼: `단어 / 품사 / 예문 / 유의어·반의어 / 난이도(CEFR or 학년)`
  - 30~50단어면 워크숍 실습에 충분 (많을 필요 없음)

> 💡 **데이터 표준 예시** (smilepat/vocabulary-db `9000vocab_master_table.csv` 구조 그대로):
> | 단어 | Parts of Speech | Example Sentence | Synonyms/Antonyms | CEFR/Grade | Korea Curriculum |
> |------|------|------|------|------|------|
> | the | definite article | This is the book I want. | that, this / a | A1 | 초등 |
>
> 이 6컬럼이 "잘 만든 단어장"의 황금 표준입니다. 이대로 따라 만들면 어떤 앱이든 붙습니다.

## 모듈 구성 (4시간 기준)

```
[0:00] 모듈 0  마인드셋 + 환경 세팅          (30분)
[0:30] 모듈 1  첫 화면 — 플래시카드 한 장      (60분)  ← 성취감 구간
[1:30] 휴식                                  (10분)
[1:40] 모듈 2  내 단어장 연결하기             (50분)  ← 핵심 구간
[2:30] 모듈 3  학습 기능 추가 (퀴즈·반복)     (50분)
[3:20] 모듈 4  학생에게 배포하기              (25분)  ← 감동 구간
[3:45] 모듈 5  공유 + 다음 단계 안내          (15분)
```

## 모듈 0 — 마인드셋 + 환경 세팅 (30분)

### 목표
"AI에게 말로 시키면 진짜 프로그램이 나온다"를 **눈으로** 확인한다.

### 진행
1. **데모 충격 (5분)**: 운영자가 라이브로 한 문장 입력 → 동작하는 카드 등장
   ```
   "영어 단어 카드를 보여주고, 클릭하면 한국어 뜻이 나오는
    HTML 파일 하나를 만들어줘. 단어는 apple(사과), book(책) 두 개."
   ```
2. **결과물 더블클릭 (10분)**: AI가 준 코드를 `메모장`에 붙여넣고 `card.html`로 저장 → 더블클릭 → 브라우저에서 동작 확인
   - ⚠️ 저장 시 "모든 파일" 선택, 확장자 `.html` 반드시 확인
3. **바이브 코딩 루프 설명 (5분)**:
   ```
   ① 작게 시킨다 → ② 직접 써본다 → ③ 고칠 점을 말로 → ④ 반복
   ```
4. **에러 대처 원칙 (5분)**: "빨간 글씨가 떠도 당황 금지. **그대로 복사해서 AI에게 붙여넣기.**"

### 통과 기준
- [ ] 모든 교사가 자기 화면에서 카드 하나를 클릭해 뜻을 봤다.

## 모듈 1 — 첫 화면: 플래시카드 한 장 (60분)

### 목표
샘플 단어 3~5개로 **넘기기 되는 플래시카드**를 완성한다.

### 단계별 프롬프트 (한 번에 하나씩!)

**1단계 — 기본 카드**
```
영어 단어 플래시카드 웹페이지를 HTML 파일 하나로 만들어줘.
- 화면 가운데 큰 카드 한 장
- 카드를 클릭하면 앞면(영어 단어) ↔ 뒷면(한국어 뜻)이 뒤집힘
- 단어 3개: apple(사과), brave(용감한), improve(향상시키다)
- 디자인은 깔끔하고 글씨 크게, 모바일에서도 잘 보이게
```

**2단계 — 넘기기 버튼**
```
좋아. 이제 카드 아래에 '이전 / 다음' 버튼을 추가해서
여러 단어를 넘겨볼 수 있게 해줘. 그리고 'OO / 3' 처럼
지금 몇 번째인지 표시해줘.
```

**3단계 — 예문 추가**
```
카드 뒷면에 한국어 뜻 아래에 영어 예문도 같이 보여줘.
예문: apple → "I ate an apple.", brave → "She is a brave girl."
```

### 자주 막히는 지점 & 해결
| 증상 | 해결 |
|------|------|
| 한글이 깨져 보임 | "한글이 ???로 깨져. UTF-8 인코딩으로 저장되게 해줘"로 다시 요청 + 저장 시 인코딩 UTF-8 |
| 버튼이 안 눌림 | 에러 화면(F12 → Console 빨간 글씨) 복사해서 AI에 붙여넣기 |
| 코드가 너무 길어 헷갈림 | "전체 코드를 처음부터 끝까지 한 파일로 다시 줘"라고 요청 |

### 통과 기준
- [ ] 버튼으로 단어를 넘기고, 뒤집어 뜻·예문을 볼 수 있다.

## 모듈 2 — 내 단어장 연결하기 (50분) ★핵심

### 목표
샘플 3개가 아니라 **내가 만든 30~50단어**가 앱에 들어간다.

### 방법 A — CSV 붙여넣기 (가장 쉬움, 추천)
1. 구글시트에서 내 단어장 → `파일 > 다운로드 > CSV`
2. CSV를 메모장으로 열어 **내용 전체 복사**
3. AI에게:
```
내 단어장 데이터를 줄게. 이 단어들로 플래시카드가 동작하게
코드를 바꿔줘. (앞면=단어, 뒷면=뜻+예문)

[여기에 CSV 내용 통째로 붙여넣기]
```

### 방법 B — 시트를 그대로 데이터로 (확장형, 선택)
> 단어가 100개 넘거나 자주 바뀌면 → 구글시트를 데이터 소스로 연결.
> 이건 **모듈 5(심화)**에서 안내. 워크숍 본 과정은 방법 A로 충분.

### 데이터 품질 = 앱 품질 (강조 5분)
- "쓰레기 데이터 → 쓰레기 앱." 예문 없는 단어는 앱에서도 빈칸이다.
- 컬럼 이름을 일관되게: `단어/뜻/예문`을 끝까지 똑같이.

### 통과 기준
- [ ] 내 단어 30개 이상이 앱에서 정상으로 넘어간다.

## 모듈 3 — 학습 기능 추가 (50분)

> 욕심내지 말고 **아래 중 1~2개만** 골라 추가. 다 하려다 다 못 끝낸다.

### 옵션 A — 4지선다 퀴즈 (가장 인기)
```
이제 '퀴즈 모드' 버튼을 추가해줘.
- 단어를 보여주고, 보기 4개(한국어 뜻) 중 정답 고르기
- 보기 중 1개는 정답, 3개는 다른 단어의 뜻에서 랜덤
- 맞으면 초록색, 틀리면 빨간색 + 정답 표시
- 10문제 후 점수(맞은 개수)를 보여줘
```

### 옵션 B — 간격 반복 (Leitner 5-Box, 교육적으로 강력)
```
'학습 모드'에 간단한 복습 시스템을 넣어줘.
- 내가 '안다/모른다' 버튼을 누름
- '모른다'한 단어는 더 자주 다시 나오게
- '안다'한 단어는 덜 나오게
- 진행 상황을 브라우저에 저장해서 다음에 와도 이어지게(localStorage)
```

### 옵션 C — 진도/결과 표시
```
오늘 학습한 단어 수, 정답률, 아직 못 외운 단어 목록을
한눈에 보는 '대시보드' 화면을 추가해줘.
```

### 통과 기준
- [ ] 학생이 "학습했다"고 느낄 상호작용이 1개 이상 동작한다.

## 모듈 4 — 학생에게 배포하기 (25분) ★감동 구간

### 목표
내 컴퓨터 속 파일을 → **카톡으로 보낼 수 있는 링크**로.

### 단계 (Netlify Drop — 가장 쉬움, 로그인도 선택)
1. 브라우저에서 **app.netlify.com/drop** 접속
2. 내 `index.html` 파일을 **화면에 드래그 앤 드롭**
3. 몇 초 후 **`https://...netlify.app` 링크 생성**
4. 링크를 휴대폰으로 열어 직접 학습해 보기 → 학생에게 공유

> 대안: **Vercel** (vercel.com) — 구글 로그인 후 파일 업로드. 교사님 환경 표준.

### ⚠️ 배포 전 체크
- [ ] 파일 이름이 **`index.html`** 인가? (아니면 첫 화면이 안 뜸)
- [ ] 휴대폰(모바일)에서 글씨·버튼이 잘 보이는가?
- [ ] 개인정보·정답 데이터가 노출돼도 괜찮은 수준인가?

### 통과 기준
- [ ] 자기 휴대폰에서 **링크로** 자기 앱을 열어 학습했다.

## 부록 A — 만능 프롬프트 카드 (인쇄용)

**🟢 시작할 때**
```
나는 코딩을 전혀 모르는 영어 교사야. 초보도 이해할 수 있게,
HTML 파일 하나로 동작하는 [무엇]을 만들어줘.
복잡한 설치 없이 더블클릭만으로 실행되게 해줘.
전체 코드를 한 번에 줘.
```

**🟡 기능 추가할 때**
```
좋아. 이제 [기능 하나]를 추가해줘.
나머지는 그대로 두고, 전체 코드를 다시 한 번에 줘.
```

**🔴 막혔을 때 (에러)**
```
이런 에러가 떴어. 초보도 알 수 있게 원인과 해결을 설명하고,
고친 전체 코드를 다시 줘.

[에러 메시지 그대로 붙여넣기]
```

**🔵 데이터 넣을 때**
```
내 단어장 데이터를 줄게. 이 데이터로 동작하게 바꿔줘.
[CSV/표 내용 붙여넣기]
```

## 부록 B — 교사가 빠지는 3대 함정 (운영자 강조 멘트)

1. **처음부터 완벽한 앱을 노린다** → 80%는 못 끝낸다. **카드 한 장부터.**
2. **데이터를 대충 만든다** → 단어장 품질 = 앱 품질. 사전과제가 진짜 핵심.
3. **AI를 마법으로 기대한다** → AI는 "설명한 만큼" 만든다. **명확한 요구 = 교사의 진짜 실력.**

## 부록 D — "왜 이 워크숍이 가능한가" (참가자 동기 부여)

> 여러분은 이미 **가장 어려운 두 가지**를 가지고 있습니다.
> 1. **양질의 단어장 데이터** (교사의 평생 자산)
> 2. **무엇을 어떻게 가르칠지에 대한 교육적 설계**
>
> 과거엔 여기에 "개발자"가 반드시 필요했습니다.
> 지금은 그 자리를 **AI + 명확한 말**이 대신합니다.
> 코딩은 더 이상 장벽이 아니라, 여러분의 수업 설계를 실현하는 **도구**일 뿐입니다.
