# 워크샵: 생성형 AI로 영어 학습 앱 만들기 (초보 바이브코더용)

> **대상**: 코딩 안 해본 영어 선생님. **설치 거의 없음**(브라우저 + 계정만).
> **목표**: 3시간 안에 **작동하는 영어 학습 앱 하나**를 손에 쥔다.
> **방식**: 파이썬·터미널 X. **생성형 AI에게 말로 시키고**, 당신은 교육적 판단·검증.
> **결과물**: 단어 학습 + 퀴즈가 되는 웹앱 (링크로 공유 가능).

---

## 0. 워크샵 전 준비 (참가자 사전 안내)

설치할 것 **없습니다.** 아래 계정만 미리 만들어 오세요(전부 무료 시작 가능):

| 도구 | 용도 | 비고 |
|---|---|---|
| **생성형 AI** (Claude·ChatGPT·Gemini 중 아무거나) | 콘텐츠·앱 코드 생성 엔진 | 워크샵의 심장 (어느 것이든 OK) |
| **Google 계정** | Google Sheets(데이터 보관) | 대부분 이미 있음 |
| **최신 크롬/엣지 브라우저** | index.html 미리보기 | 더블클릭으로 앱 열기 |
| (선택) **Netlify 계정** (netlify.com) | 완성 앱을 공개 URL로 배포 | 세션5, 계정 없어도 즉시 가능 |

> 💡 "바이브코딩"이란? **코드를 외워 치는 게 아니라, AI에게 원하는 걸 말로 설명하고
> 결과를 보고 다시 고쳐달라고 하는** 방식입니다. 영어 선생님의 무기는 **무엇을 가르칠지 아는 것.**

**오늘의 약속 3가지**
1. 작게 시작 (단어 20개로). 2. AI가 준 걸 **꼭 눈으로 검증**. 3. 막히면 AI에게 "더 쉽게 설명해줘".

## 세션 0. 내 앱 한 줄로 정하기 (15분)

**활동**: 옆 사람에게 한 문장으로 설명해보세요.
> "이 앱은 **[누구]**가 **[무엇]**을 **[어떻게]** 배우게 한다."

예시:
- "이 앱은 **중1**이 **교과서 필수 단어**를 **플래시카드+퀴즈로** 외우게 한다."
- "이 앱은 **수능 준비생**이 **빈출 어휘**를 **예문 빈칸 채우기로** 익히게 한다."
- "이 앱은 **초등 4학년**이 **동물 단어**를 **그림 매칭으로** 배우게 한다."

> ⚠️ 욕심내지 마세요. **단어 20개짜리 한 기능**이면 충분합니다. 오늘은 "씨앗"을 심는 날.

## 세션 1. AI와 함께 앱 기획서 쓰기 (35분)

**왜**: AI에게 "앱 만들어줘"라고만 하면 엉뚱한 게 나옵니다.
**1쪽 기획서**를 먼저 만들면 결과가 확 좋아집니다.

**활동**: Claude/ChatGPT에 아래를 그대로 붙여넣고, 대화하며 채우세요.

**복붙 프롬프트**:
```
너는 영어교육 앱 기획을 돕는 PM이야. 나는 코딩을 모르는 영어 선생님이야.
내 앱 한 줄: "[세션0에서 정한 문장]"
이걸 바탕으로 아래를 채운 1쪽 기획서를 표로 만들어줘. 어려운 용어는 풀어서 설명해줘.
- 대상 학습자(나이/수준)
- 핵심 기능 딱 1개 (MVP)
- 화면 구성(어떤 버튼/카드가 보이나)
- 학습 데이터(단어 몇 개, 어떤 정보가 필요한가)
- "성공"의 기준(학습자가 뭘 할 수 있으면 성공인가)
질문이 있으면 한 번에 3개씩만 물어봐.
```

**당신이 할 판단**: AI가 제안한 기능이 **실제 교실에서 쓸모 있나?** 너무 복잡하면
"기능 1개로 더 줄여줘"라고 하세요.

**산출물**: 1쪽 기획서 (캡처하거나 메모장에 저장).

## 세션 2. AI로 학습 콘텐츠 만들기 (40분)

**왜**: 앱의 알맹이는 **콘텐츠(단어·지문·문제)**입니다. 이걸 AI로 빠르게 만들고
**Google Sheets**에 보관합니다. (Sheets가 우리의 "데이터베이스")

### 2-1. 단어 20개 만들기
**복붙 프롬프트**:
```
내 앱 대상은 "[대상]"이야. 이 수준에 맞는 영어 단어 20개를 표로 만들어줘.
칸은 정확히 이렇게: word_id, word, 품사, 한국어뜻, 난이도(CEFR), 예문.
- word_id는 단어를 소문자로 (Economy -> economy). 나중에 연결의 열쇠야.
- 예문은 대상 수준에 맞게 쉽게.
복사해서 구글시트에 붙일 수 있게 CSV(쉼표구분)로 출력해줘.
```
→ 결과를 복사 → **Google Sheets** 새 시트에 붙여넣기(붙여넣기 시 "텍스트를 열로 분할").

### 2-2. 지문 3개 만들기 (선택)
**복붙 프롬프트**:
```
방금 단어들 중 일부가 자연스럽게 들어가도록, [대상] 수준의 영어 지문 3개를 만들어줘.
각 40단어 내외. 칸: passage_id(P001..), 제목, 난이도, 본문.
어떤 단어가 어느 지문에 들어갔는지도 따로 표로 알려줘.
```

### 2-3. 퀴즈 문제 만들기
**복붙 프롬프트**:
```
위 단어 20개로 4지선다 퀴즈를 만들어줘. 칸: 단어, 문제(한국어뜻 고르기), 보기4개, 정답.
오답 보기는 비슷한 수준의 다른 단어 뜻으로 (너무 쉽거나 황당하지 않게).
```

**⚠️ 검증 (영어 선생님의 진짜 역할)**:
- 뜻·예문이 **정확한가?** (AI는 가끔 틀린 뜻·어색한 예문을 만듭니다)
- 난이도가 대상에 맞나? 오답 보기가 너무 뻔하지 않나?
- **틀린 건 그 자리에서 고치세요.** 이게 AI 못 하는, 선생님만의 가치입니다.

**산출물**: Google Sheets에 단어/지문/퀴즈 시트.

## 세션 3. AI로 앱 만들기 (50분) — 핵심

**왜**: 이제 콘텐츠를 **작동하는 앱**으로. 특정 도구 기능(Artifact 등)에 의존하지 않고,
**어떤 생성형 AI든** 쓸 수 있게 — AI에게 **파일 하나(`index.html`)**로 된 앱을 만들게 합니다.

> 🤔 왜 "파일 하나(index.html)"인가?
> - HTML+디자인(CSS)+동작(JS)+데이터가 **한 파일**에 다 들어 있으면, **더블클릭만 하면 브라우저에서 바로** 열립니다.
> - 설치·빌드(복잡한 변환)도 필요 없고, 나중에 **그 파일 하나만 올리면 배포**도 끝납니다(세션5).
> - Claude·ChatGPT·Gemini 등 **무엇을 쓰든 동일하게** 됩니다. (도구 종속 X)

### 3-1. 앱 생성 프롬프트 (어떤 생성형 AI든)
쓰는 AI에 아래를 붙여넣고, 맨 아래에 **세션2의 단어 CSV를 그대로 이어붙이세요**.

**복붙 프롬프트**:
```
코딩 모르는 영어 선생님을 위해, 영어 단어 학습 앱을 '하나의 index.html 파일'로 만들어줘.
조건: HTML+CSS+JavaScript를 한 파일에. 설치·빌드·외부 라이브러리 없이, 더블클릭하면 브라우저에서 바로 작동.
기능(MVP 1개에 집중):
1) 단어 카드: 영어 단어를 보여주고, 누르면 뜻·예문이 보인다(플래시카드).
2) "다음" 버튼으로 단어를 넘긴다. 진도(3/20) 표시.
3) 퀴즈 모드 버튼: 4지선다로 뜻 맞히기, 점수 표시.
디자인: 크고 깔끔한 글씨, 모바일에서도 잘 보이게, 한국어 UI.
단어 데이터는 아래 목록을 코드(JavaScript) 안에 직접 넣어줘.
전체 코드를 복사할 수 있게 한 덩어리로 줘.
데이터:
[여기에 세션2의 단어 CSV를 붙여넣기]
```

### 3-2. 내 컴퓨터에서 미리보기 (설치 없음)
1. AI가 준 코드를 **전부 복사**.
2. 메모장(또는 VS Code) 새 파일에 붙여넣기 → **`index.html`** 이름으로 저장
   (메모장은 저장 시 파일형식 "모든 파일", 인코딩 **UTF-8**).
3. 저장한 `index.html`을 **더블클릭** → 브라우저에 앱이 뜹니다. 눌러보세요!

> 💡 더 간단히: AI 채팅이 코드 미리보기(Claude의 Artifact, ChatGPT의 Canvas 등)를 지원하면
> 거기서 바로 봐도 됩니다. 하지만 **핵심 결과물은 `index.html` 파일** — 이게 있어야 어디든 배포됩니다.

### 3-3. 안 되면? (말로 고치기)
- 빈 화면: "브라우저에서 빈 화면이야. 콘솔 에러를 어떻게 보는지 알려주고, 코드를 고쳐줘."
- 데이터가 적게: "단어가 5개만 보여. 내가 준 20개 전부 코드에 넣어줘."
- 한글 깨짐: "한글이 깨져. 파일 맨 위에 <meta charset='utf-8'> 넣어줘."

> 💡 **이게 바이브코딩의 마법**: 코드를 못 읽어도, **증상을 말로 설명**하면 AI가 고칩니다.

**산출물**: 더블클릭하면 작동하는 **`index.html`** 한 파일.

## 세션 4. 말로 고치기 — 반복 개선 (30분)

**왜**: 첫 결과는 초안입니다. **선생님 눈으로 보고 말로 고치면** 점점 좋아집니다.

**이렇게 요청해보세요 (하나씩)**:
- "단어 카드 글씨를 더 크게, 색을 부드럽게 해줘."
- "퀴즈 다 풀면 '잘했어요!' 격려 메시지와 점수를 보여줘."
- "틀린 단어만 다시 복습하는 버튼을 추가해줘."
- "발음을 위해 단어 옆에 🔊 버튼(브라우저 음성 읽기)을 넣어줘."
- "예문에서 그 단어를 굵게 표시해줘."

**한 번에 하나씩** 고치고 **매번 미리보기로 확인**하세요. (한꺼번에 시키면 꼬입니다)

**⚠️ 함정**: AI가 고치다 멀쩡하던 기능을 깨뜨릴 수 있습니다.
→ 잘 되던 버전이 나오면 **그 코드를 복사해 메모장에 백업**해두세요(되돌리기용).

## 세션 5. 배포(공유) + 다음 단계 (15분)

**왜**: 이제 `index.html`을 **인터넷에 올려** 누구나 들어오는 **공개 주소(URL)**로 만듭니다.
바이브코더에게 가장 보편적이고 쉬운 방법 순서로 안내합니다.

### 5-1. 가장 쉬움 — Netlify Drop (드래그 한 번, 설치·코딩 0)
> 단일 파일 앱 배포에 가장 빠릅니다. 계정 없이도 즉시 됩니다(계정 있으면 URL 유지·관리 가능).
1. 브라우저에서 **app.netlify.com/drop** 접속.
2. 내 **`index.html`**(또는 그 파일이 든 폴더)을 화면에 **끌어다 놓기**.
3. 잠시 뒤 **공개 URL**이 생깁니다 → 복사해서 동료·학생에게 전달.
4. (선택) 무료 가입하면 그 사이트가 유지되고, 파일을 다시 끌어다 놓으면 **업데이트**됩니다.

### 5-2. 대안 — Vercel / GitHub Pages
- **Vercel** (vercel.com): 가장 널리 쓰는 배포 서비스. GitHub 레포에 `index.html`을 올리고
  Vercel에서 그 레포를 연결하면 공개 URL + 자동 재배포. (Git에 익숙해지면 추천)
- **GitHub Pages**: 레포 Settings → Pages → 브랜치 지정 → `https://아이디.github.io/레포` 로 공개.

### 5-3. 올인원 — 만들기+배포를 한 곳에서 (AI 앱빌더)
처음부터 배포까지 한 번에 하고 싶으면, 세션3의 프롬프트를 아래 **브라우저 앱빌더**에 넣으면
앱 생성 + **공개 URL 배포**까지 한 자리에서 됩니다(무료 시작):
- **v0.dev**(Vercel) · **Bolt.new** · **Lovable** · **Replit**

### 5-4. 확인
받은 URL을 **휴대폰으로 열어** 보세요. 동료에게 보내 잘 열리는지 확인하면 진짜 배포 완료. 🎉

> 💡 어떤 길이든 핵심은 같습니다: **`index.html` 한 파일** → 인터넷의 한 주소.
> 도구(Netlify/Vercel/빌더)는 취향껏 고르세요.

### 오늘 만든 것 = "씨앗"
다음 단계로 키우는 길(집에서 천천히):
1. 단어 20 → 200개로 (시트에 줄 추가 → 앱에 다시 붙여넣기).
2. 데이터와 앱 **분리**: 시트를 "웹에 게시(CSV)" → 앱이 그 주소를 읽게.
   ("이 구글시트 CSV 주소에서 단어를 불러오게 바꿔줘"라고 AI에 요청)
3. 진짜 시스템으로: 단어·지문·문항·스킬을 **그래프 DB**로 연결
   (→ `docs/FROM_SCRATCH_어휘DB_textDB_시스템.md` 가이드 참고).

## 워크샵 핵심 5원칙 (집에 가져갈 것)

1. **작게 시작** — 단어 20개, 기능 1개. 작동부터 확인.
2. **기획서 먼저** — AI에게 시키기 전에 1쪽 기획서.
3. **선생님이 검증** — 뜻·난이도·예문은 AI 말고 **당신이** 책임.
4. **한 번에 하나씩 고치기** — + 잘 된 버전 백업.
5. **막히면 증상을 말로** — "코드를 몰라도" 고칠 수 있다.

## 부록 A. 자주 막히는 곳 & 해결 (진행자용)

| 증상 | 해결 |
|---|---|
| 한글이 깨져 보임 | 시트 붙여넣기 시 인코딩/열분할 확인. AI에 "UTF-8 CSV로 줘" |
